# Ночная Земля — интерактивный 3D-глобус (Django + Globe.gl)

Реалистичный ночной глобус. Издали видны только страны — с мягкой подсветкой и подписями. Нажмите на страну (или просто приблизьте камеру) — появятся светящиеся точки её городов; клик по городу открывает боковую панель: описание, история и великие события, компании и производство. Кнопка поиска в левом нижнем углу находит любой город или страну. Языки: русский (ru), узбекский (uz), каракалпакский (qr).

## Быстрый старт

Нужен Python 3.10+ и интернет в браузере (Globe.gl, Tailwind, шрифты и текстуры Земли подключаются через CDN).

```bash
# 1. Виртуальное окружение
python -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate

# 2. Зависимости
pip install -r requirements.txt   # Django 5.x + Django REST Framework

# 3. База данных
python manage.py migrate

# 4. Тестовые данные (Ташкент, Нукус, Москва, Токио, Нью-Йорк)
python manage.py loaddata fixtures

# 4а. Ещё 29 городов в 29 странах (Париж, Лондон, Баку, Бишкек, Бангкок, Кейптаун, Самарканд и др.)
python manage.py seed_world

# 5. (необязательно) администратор для редактирования текстов
python manage.py createsuperuser

# 6. Запуск
python manage.py runserver
```

Откройте http://127.0.0.1:8000/ — глобус, http://127.0.0.1:8000/admin/ — админка.

## Как пользоваться глобусом

| Действие | Что происходит |
|---|---|
| Глобус издали | Видны только страны: те, где есть города, подсвечены и подписаны |
| Клик по стране или её подписи | Камера подлетает к стране, появляются её города, сверху — плашка с кнопкой «Весь мир» |
| Немного приблизить камеру колесом или щипком | Появляются города рядом с центром экрана (без наложения подписей) |
| Клик по городу | Открывается панель с описанием, историей и компаниями |
| Кнопка с лупой (левый нижний угол) или клавиша `/` | Поиск по городам и странам; `↑` `↓` — выбор, `Enter` — открыть |
| `Esc` | Закрывает поиск → панель города → возвращает вид «весь мир» |

Пороги переключения вида настраиваются в `static/js/app.js`, объект `CAMERA`: `citiesFrom` (ближе — показываем города) и `citiesTo` (дальше — снова только страны). Два значения нужны, чтобы вид не мигал на границе.

## API

| Запрос | Ответ |
|---|---|
| `GET /api/cities/?lang=ru` | все города: `id, name, country, country_code, latitude, longitude, population, is_capital, summary` |
| `GET /api/cities/<id>/?lang=uz` | подробно: описание, `history` и `industry` (списки `{label, text}`) |
| `GET /api/countries/?lang=qr` | страны; `?boundary=1` добавляет GeoJSON-границы, если заполнены |

`lang` принимает `ru`, `uz`, `qr`. Неизвестное значение или пустой перевод заменяются русским.

## Структура

```
config/                 настройки и корневые маршруты
globe/models.py         Country, City (поля *_ru, *_uz, *_qr)
globe/serializers.py    локализация и разбор строк «Год — событие»
globe/views.py          главная страница и API
globe/urls.py           маршруты
globe/fixtures/fixtures.json   начальные данные
templates/index.html    страница, панель, переключатель языков
static/js/app.js        глобус, режимы «страны / города», поиск, API, панель, i18n
static/css/styles.css   раскладка, свечение точек, панель
static/data/countries.geojson  границы стран (Natural Earth, public domain)
```

## Готовый набор городов (`seed_world`)

```bash
python manage.py seed_world            # добавить недостающие страны и города
python manage.py seed_world --dry-run  # только показать, что будет добавлено
python manage.py seed_world --update   # перезаписать тексты городов из набора
```

Команда безопасна для повторного запуска: страны ищутся по коду, города — по паре «страна + название (ru)». Всё, что уже есть в базе (в том числе ваши правки из админки), остаётся нетронутым, пока не указан `--update`. Данные лежат в `globe/seed_data/` (Европа, Азия и Африка, Америка и Океания, `more.py` — новые страны), чтобы набор можно было расширять обычным Python-файлом. Для новой страны добавьте строку в `COUNTRIES` (`globe/seed_data/__init__.py`), для города — словарь в любой из списков `CITIES`.

Сейчас в наборе: Париж, Лондон, Берлин, Рим, Стамбул, Каир, Пекин, Дели, Сеул, Дубай, Астана, Самарканд, Сидней, Сан-Паулу, Мехико и новые:
Бишкек (Кыргызстан), Душанбе (Таджикистан), Ашхабад (Туркменистан), Баку (Азербайджан), Мадрид и Барселона (Испания), Торонто (Канада), Буэнос-Айрес (Аргентина), Кейптаун (ЮАР), Эр-Рияд (Саудовская Аравия), Бангкок (Таиланд), Джакарта (Индонезия), а также Бухара (Узбекистан) и Санкт-Петербург (Россия).

Если база уже создана, достаточно снова выполнить `python manage.py seed_world` — добавятся только недостающие страны и города, ваши правки не тронутся.

## Как добавить город

В админке создайте `City`: координаты, название и тексты на трёх языках. Поля «История» и «Компании и производство» заполняются по одной записи на строку в формате `Год — событие` или `Название — описание`; часть до « — » выделяется в панели как год или название. Новая точка появится на глобусе сразу.

## Продакшен

```bash
export DJANGO_SECRET_KEY="длинная-случайная-строка"
export DJANGO_DEBUG=0
export DJANGO_ALLOWED_HOSTS="example.com"
python manage.py collectstatic
```

Статику при `DEBUG=0` раздаёт веб-сервер (nginx) или WhiteNoise; приложение запускайте через gunicorn.

## Важно

- Тексты на узбекском и каракалпакском (латиница) подготовлены как черновик: их стоит показать носителю языка. Это относится и к новым городам из `more.py`. Фактические данные (даты, компании) сверьте с источниками перед публикацией.
- Численность населения округлена и приблизительна (Токио — префектура, Нью-Йорк — оценка).
- Каракалпакский добавлен в интерфейс как `qr`, в атрибут `lang` страницы подставляется стандартный код `kaa`.
